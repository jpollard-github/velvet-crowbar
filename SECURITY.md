# Security policy

This uncommitted Phase 0 repository has no deployed service or public security
contact yet. Report suspected issues privately to Jason Pollard; do not include
private editorial content, credentials, or exploit payloads containing real
workplace material in a public issue.

See [Security and privacy](docs/SECURITY-AND-PRIVACY.md) for the threat model,
controls, and limitations. Phase 0 must not be described as legally safe,
anonymous, zero-knowledge, end-to-end encrypted, or production hardened.
